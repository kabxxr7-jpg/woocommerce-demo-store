# Fonts

Latin subsets (U+0000-00FF plus common punctuation, the euro sign and arrows) of two fonts that ship with the
Twenty Twenty-Five theme, made with fonttools `pyftsubset` to cut their size for the speed work:

| File | From | Size before / after |
|---|---|---|
| `Manrope-VariableFont_wght-latin.woff2` | Manrope, Copyright (c) 2018 The Manrope Project Authors | 55 KB / 24 KB |
| `Vollkorn-VariableFont_wght-latin.woff2` | Vollkorn, Copyright (c) 2005-2018 Friedrich Althausen | 191 KB / 70 KB |
| `Vollkorn-Italic-VariableFont_wght-latin.woff2` | Vollkorn Italic, same | 163 KB / 58 KB |
